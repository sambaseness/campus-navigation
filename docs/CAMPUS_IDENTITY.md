# Campus Identity

The application targets **École Supérieure Polytechnique de Dakar (ESP)**, affiliated with Cheikh Anta Diop University (UCAD).

Official ESP information places the school at Université Cheikh Anta Diop de Dakar, Corniche Ouest, BP 5085 Dakar-Fann.

For the remote mapping phase, OSM places the main ESP campus feature around:

- Latitude: `14.68102`
- Longitude: `-17.46643`

Other mapped ESP nodes are nearby, so the project should use a campus area/boundary rather than treating one OSM point as the whole campus.

## Important distinction

The map center is only a camera starting point.

It is **not** the calibration origin, campus boundary, or surveyed reference point.
